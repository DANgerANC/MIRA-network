# План развития MIRA

## Core 0.1 — фундамент

Реализовано в исходном коде; базовая демонстрация Windows x86-64 пройдена
26 сентября 2026. [Подробные результаты](docs/demo-windows.md).
Основной сценарий приёмки выполнен на Windows GNU и Linux x86-64; дополнительные
проверки прошли в Linux ARM64/QEMU и Android ARM64. Границы этих результатов
описаны в отчётах приёмки. В исходном коде реализовано:

- CLI: version, status, system, config, serve; JSON для информационных команд.
- Определение ОС, архитектуры, CPU, RAM, дисков, сетевых интерфейсов, hostname и IP.
- Папки config/data/logs, создание TOML, изменение настроек и сохранение на диск.
- INFO/WARN/ERROR/DEBUG, вывод в stderr и файлы с ротацией.
- HTTP API v1: status, system, version.
- Встроенная диагностическая страница.
- Общие модели и логика, независимые от Thundercloud и MQTT.

Условия завершения 0.1, которые ещё предстоит подтвердить:

- [x] Собрать на Windows x86-64 и выполнить сценарий приёмки.
- [x] Собрать на Linux x86-64 и выполнить тот же сценарий.
- [x] Сохранить полученный Cargo.lock в репозитории.
- [x] Подтвердить сохранение настроек после перезапуска на Windows.
- [x] Подтвердить согласованность CLI status и HTTP status на Windows.
- [x] Выполнить сценарий на Linux ARM64 в QEMU.
- [ ] Выполнить сценарий на физическом Linux ARM64-устройстве (например, Raspberry Pi).

Дополнительно проверено:

- [x] Выполнить сценарий на Android ARM64 через ADB shell.
- [ ] Проверить Windows x86-64 с MSVC toolchain.
- [ ] Проверить запуск в APK-песочнице Android.

Сценарий: [docs/acceptance.md](docs/acceptance.md).
